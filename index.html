CoSAI-RM ontology 0.1.0

OWL 2 DL TBox and catalog for the Coalition for Secure AI Risk Map. Catalog rows are named individuals. Alignments to OpenCRE, BFO 2020, MITRE D3FEND 1.5.0, and SPDX 3.1 use SKOS matches, not OWL equivalence.

Source issue: cosai-oasis/secure-ai-tooling#388. YAML snapshot: CoSAI-RM commit 3a896b8.

Example: risk to ATLAS, D3FEND, and OpenCRE

For a CoSAI risk, list ATLAS terms, D3FEND techniques on mitigating controls, and OpenCRE nodes:

PREFIX cosai: <https://cosai-oasis.github.io/ontology/cosai-rm#>
PREFIX skos:  <http://www.w3.org/2004/02/skos/core#>
PREFIX rdfs:  <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?risk ?atlas ?d3f ?cre ?control
WHERE {
  ?risk a cosai:Risk .
  OPTIONAL { ?risk cosai:mapsTo ?atlas . }
  OPTIONAL {
    ?control cosai:mitigates ?risk ;
             skos:closeMatch|skos:relatedMatch ?d3f .
    FILTER(CONTAINS(STR(?d3f), "d3fend.mitre.org"))
  }
  OPTIONAL {
    ?risk skos:relatedMatch ?cre .
    FILTER(CONTAINS(STR(?cre), "opencre.org/cre"))
  }
}
